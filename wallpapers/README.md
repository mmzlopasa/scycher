# Scycher Wallpapers

Eight original wallpapers, each in a **dark** and a **light** version, 2880 × 2880 (square, so they fill a tablet in portrait and landscape).

| Design | Idea |
| --- | --- |
| Bloom | Petals fanning out from a point low on the canvas |
| Tide | Stacked waves rolling in |
| Orbit | Concentric rings around an off-canvas sun |
| Aurora | Glowing ribbons sweeping across |
| Mesh | Pure colour – a soft mesh gradient |
| Dune | Layered hills at sunset |
| Prism | Overlapping panes of tinted glass |
| Liquid | Glass droplets with a specular highlight |

They are procedurally drawn by [`tools/wallpapers/generate.py`](../tools/wallpapers/generate.py) – no stock or third-party imagery. Inside Scycher they live in **Settings › Appearance › Scycher wallpapers** (or the wallpaper button in edit mode); with *Match dark mode* the launcher swaps dark ↔ light with the system theme.
